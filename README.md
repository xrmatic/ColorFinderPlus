# Color Finder Plus

Color Finder Plus is a Manifest V3 extension for Chromium-based browsers that identifies exact colors on web pages.

## Features

- live color picker with a magnified cursor preview
- Hex and RGB readout for the hovered and selected pixel
- drag-to-select box that extracts all visible colors in the chosen region
- frequency-sorted color list in the side panel
- automatic 4, 8, 16, and 32-color palette suggestions from multi-color selections
- works in Chrome, Microsoft Edge, Brave, Opera, Vivaldi, and other Chromium-based browsers

## Load the extension locally

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this project folder.

## Use the extension

1. Click the Color Finder Plus toolbar icon to open the side panel.
2. Choose `Start Picker` to inspect a single page color.
3. Choose `Draw Selection Box` to collect all visible colors within a region.
4. Click any swatch or palette chip in the side panel to copy its Hex value.
5. Open the side panel `Settings` button or the browser's extension management page to adjust density, visible sections, result limits, and font sizes.
